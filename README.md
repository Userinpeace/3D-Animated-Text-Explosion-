# 3D-Animated-Text-Explosion-
A fully responsive and interactive web animation using HTML, CSS, JavaScript, and the powerful Anime.js library.

===========================================
Animated Text Splash Page with Welcome GIF
===========================================

Project Description:
--------------------
This project is a visually engaging splash screen created using HTML, CSS, and JavaScript (with Anime.js). The main page displays animated 3D text that reacts to hover events, and includes a clickable exclamation mark (!) that opens a separate "welcome.html" page featuring a full-screen GIF.

Features:
---------
1. Animated 3D rotating text using CSS and Anime.js.
2. Hover effect on each letter with smooth transform animations.
3. Clickable "!" symbol that opens a new page in a separate tab.
4. The welcome page displays a fullscreen animated GIF.

File Structure:
---------------
- index.html          : Main splash page with animated text and clickable link.
- style.css           : CSS styles for text animation, layout, and hover effects.
- script.js           : JavaScript file using Anime.js to animate text on hover.
- welcome.html        : Secondary page displaying a full-screen welcome GIF.
- welcome.gif         : The animated GIF shown on the welcome page.
- README.txt          : Project description and setup guide.

How to Use:
-----------
1. Open index.html in a web browser.
2. Hover over the animated text to see individual letter effects.
3. Click on the "!" symbol to launch the welcome page in a new tab.
4. The welcome page displays an animated GIF in fullscreen.

Dependencies:
-------------
- Anime.js CDN (included in index.html)

Installation & Setup:
---------------------
No installation required. Simply ensure all files are in the same directory.
Make sure your browser has access to load local files, or host them on a server.

Customization:
--------------
- To change the displayed text, edit the spans inside <div id="textElement"> in index.html.
- Replace welcome.gif with any other GIF of your choice for the welcome screen.
- Modify styles in style.css for colors, animation speed, or font size.
